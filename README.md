# 凡尘问道 v2.1

一介凡人的长生路 — 单机文字修仙小游戏。手机浏览器直接打开即玩。
题材取法《凡人修仙传》：青石村 → 七玄门 → 黄枫谷 → 坠魔谷 → 乱星海 → 灵界。

## 玩法

- **开局**：取一个道号，随机掷灵根（伪灵根 → 天灵根共 6 档），灵根决定修炼速度。
- **半放置**：时间自动流逝（1.5 秒 = 游戏内 1 天），挂机也会涨修为，练气小层自动突破。
- **打坐**：一次坐 30 天，修为大涨，但消耗**真元**。真元上限随境界提升，每 45 日才回一点——不能一直坐。
- **悟道**：打坐后有概率触发《凡人修仙传》相关选择题。答对修为大涨，答错倒扣。也可在「世事」页主动参悟（有冷却）。
- **斗法（肉鸽式回合）**：游历撞见对手、或主动点「斗法」，进入回合制。先看对手**意图**（扑击 / 蓄力重击 / 术法 / 守御），再从 **猛攻 / 守势 / 术法 / 遁走** 里选一手；打赢后从三张战利品里挑一样（高境界有时挑两样）。
- **突破**：小层自动，大境界手动。成功率受灵根、悟性、破障丹影响；**没有对应丹药也能硬冲，但成功率减半**。
- **强制寻丹差事**：修到一境尽头又缺丹时，差事自动找上门。这是**第一要务**，期间打坐、游历、斗法、突破全部锁死，必须把它走完（多步流程：打听 → 备料 → 守炉斗法 → 开炉）。材料不够可以就地采集，坊市也新增了材料栏。
- **支线差事**：坊市式的跑腿 / 收购 / 清剿，接了再做，给灵石与声望。
- **主线剧情**：9 章，随境界解锁，跟着凡人流走。
- **装备**：法器 / 护身 / 饰品 三栏，品相（凡良上极灵）决定加成与售价，行囊里可看对比箭头。
- **战斗力**：由攻伐、护体、气血、灵力、功法、灵根、悟性综合算出，顶栏直接显示，斗法前可和对手比一比。
- **寿元**：初始 16 岁，练气期上限 50 岁。寿元耗尽即坐化；一路走到渡劫成功则**白日飞升**（结算里会告诉你这一世共耗了多少真实时间）。

## 存档

- 进度保存在浏览器本地，刷新、关闭再打开都还在。
- **换设备或换浏览器 = 新档**。
- 「见闻」页可**导出 / 导入存档码**，建议偶尔导出备份。
- **「重开一世」**会清掉本机存档，回到取名字那一步；点了才清，不点不动。
- 支持「添加到主屏幕」，之后无网络也能打开继续玩。

## 部署到 GitHub Pages

1. 新建公开仓库，把本目录所有文件上传到仓库根目录（`index.html` 必须在根）。
2. Settings → Pages → Source 选 **Deploy from a branch** → 分支 `main`、目录 `/ (root)` → Save。
3. 等 1–2 分钟，打开 `https://<用户名>.github.io/<仓库名>/`。
4. 更新代码后重新上传即可；`sw.js` 里的 `CACHE` 版本号记得一起改，避免旧缓存。

## 文件

- `index.html` — 整个游戏（单文件，零依赖）
- `manifest.webmanifest` / `sw.js` / `icon-*.png` — PWA 离线与主屏图标
