# 凡尘问道

一介凡人的长生路 — 单机文字修仙小游戏。手机浏览器直接打开即玩。

## 玩法

- **开局**：取一个道号，随机掷灵根（伪灵根 → 天灵根共 6 档），灵根决定修炼速度。
- **半放置**：时间自动流逝（1.5 秒 = 游戏内 1 天），修为自动累积，练气小层自动突破。
- **大境界突破**必须手动点：有失败率，失败吐血掉修为、还要养伤；且需要对应丹药（如筑基丹）。
- **游历**：7 个区域按境界解锁，随机事件三选一，遇敌自动结算战报。
- **寿元**：初始 16 岁，练气期上限 50 岁。游历、闭关、冲击瓶颈都烧时间，寿元耗尽即坐化重开。
- **成长**：功法 5 部、法器攻防两栏、丹药、坊市买卖。

## 存档

- 进度保存在浏览器本地，刷新、关闭再打开都还在。
- **换设备或换浏览器 = 新档**。
- 游戏内「见闻」页可**导出 / 导入存档码**，建议偶尔导出备份，防止清浏览器缓存丢档。
- 支持「添加到主屏幕」，之后无网络也能打开继续玩。

## 本地运行

直接双击 `index.html` 即可；也可用任意静态服务器：

```bash
python3 -m http.server 8000
```
